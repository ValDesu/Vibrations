# Vibrations

Pose-to-pose toon animation for Humanoid characters in Unity. Set a few key poses; Vibrations snaps between
them with springy tweens (overshoot, anticipation, overlap, follow-through) and bakes a Humanoid
`AnimationClip`.

**Open it:** Window → Vibrations. Pick a Humanoid character, click **New** (or use a template), pose with the
Scene view handles, add poses, press Play, then **Export Clip**.

Requires Unity 6 and a Humanoid rig (Mixamo works out of the box).

Full documentation, install instructions and tips: see the repository README.
